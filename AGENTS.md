## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project coordination

For tasks, proposals, implementation, review, or feedback, read
`docs/PATRIK_WORKFLOW.md`. Unless assigned a bounded worker role, act as
orchestrator: keep the outcome and next action clear, get approval for new ideas,
and delegate approved work. Workers follow their handoff and return evidence.
Direct requests already authorize their scope. Explain results and the main logic
in simple technical English; use Answer with HTML when a visual helps.
For engineering skills, use `docs/agents/issue-tracker.md` and
`docs/agents/domain.md`. Preserve this repo's existing project rules.
