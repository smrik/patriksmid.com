# patriksmid.com

The GitHub home for the patriksmid.com website and its project work.

## Repository status

The current default branch is a starting point for the project. Website source
and a build manifest have not yet been added to this branch. This workflow setup
adds task, review and agent instructions; it does not publish or update a website.

No install, build or test command is defined here yet. Add those instructions
with the reviewed website source so that a fresh checkout can reproduce it.

## Plan and review work

Use [issues](https://github.com/smrik/patriksmid.com/issues) to describe the result
you want or give feedback. The orchestrator proposes new ideas for approval and
delegates approved implementation. Pull requests provide the reviewable changes
and their verification evidence.

The next source-integration task should identify the intended website branch,
include its build configuration, and verify a local preview. Keep live deployment
as a separate, approved step.
